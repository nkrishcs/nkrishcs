## 👨‍💻 About Me & Leadership

I am a Computer Science student with a **Cybersecurity Emphasis** and an **Information Systems Minor** at the **University of Wisconsin-La Crosse** (Class of 2028). I focus on scalable software development, systems security, and leading student engineering communities.

### 🏆 Campus Leadership & Impact
- 💻 **President | CODERS Club** (2026–2027): Lead the executive board organizing hands-on technical workshops, student software builds, and tech industry networking sessions.
- 🌍 **President | International Student Organization (ISO)** (2026–2027): Direct executive planning for campus-wide cultural initiatives, student advocacy, and community integration.
- 🏛️ **Senator | UWL Student Association** (2025–2027): Advocate for student policy and direct student body concerns to university leadership.
- 💼 **Treasurer (Asian Student Org) & Secretary (American Sign Language)** (2025–2026): Oversaw financial allocations, club records, and event operations.

### 🚀 Key Technical Highlights
- **CODERS Club Website**: Engineered persistent navigation headers and responsive UI components using Angular, TypeScript, and CSS.
- **Task List Application**: Built an interactive task tracker using Vanilla JavaScript, CSS Flexbox, and browser Local Storage for dynamic state persistence.
- **Reading Log Tracker**: Implemented custom linear search and bubble sort algorithms in Python to manage structured datasets backed by MySQL.
- **Business Analytics Research**: Authored a 4,000-word analysis investigating the market impact and data ecosystem changes from Salesforce's acquisition of Tableau.
